## Tutoriais do Lovable

<AccordionGroup>
  <Accordion title="Build an AI-Powered Calorie Tracking WebApp">
    <iframe width="100%" height="315" src="https://www.youtube.com/embed/c0zhLzcVJRI?si=7vcZf5eoxIobOxdE" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen />

    Neste tutorial, vamos te guiar através da criação de um aplicativo de rastreamento de calorias com IA usando [Lovable](/lovable-f9060f1e/lovable-f9060f1e/editor/main#build-an-ai-powered-calorie-tracking-webapp), completo com autenticação, um design responsivo bonito, integração com OpenAI e deploy para produção.

    <Steps>
      <Step title="Configurando a Base">
        A base de qualquer projeto Lovable é um bom prompt. Para este app, aqui está um exemplo:

        ```
        Create a calorie tracking app with the following features:
        Landing page, dashboard, and a meals page.
        Input fields for meal descriptions or images, with analysis powered by GPT-4.
        Daily progress tracking and integration with Supabase for authentication and database management.
        Beautiful and mobile-responsive UI.
        ```

        Uma vez que o Lovable gera o esqueleto da UI:

        * Revise a configuração de navegação e o design da página inicial.
        * Itere no prompt para refinar o layout e garantir responsividade móvel.

        <Note>
          Seja explícito sobre começar com a UI. O Lovable funciona melhor quando as tarefas são divididas em etapas claras. Por exemplo, delineie navegação, estruturas de página e temas de design no início do prompt
        </Note>
      </Step>

      <Step title="Projetando a UI">
        O Lovable enfatiza uma abordagem passo a passo, semelhante à construção de um edifício:

        * Comece com **andaimes**: Planeje a estrutura do seu app (ex: fluxo de experiência do usuário, layout da página).
        * Adicione a **primeira camada**: Crie páginas vazias com elementos básicos de design.
        * Refine os **detalhes**: Adicione cores, animações e responsividade móvel.

        <Note>
          Se você tem designs pré-feitos no [Figma](), pode tirar screenshots e incluí-los no seu prompt do Lovable. Fornecer imagens de alta resolução garante melhores resultados.
        </Note>
      </Step>

      <Step title="Integrar Supabase para Backend e Autenticação">
        Uma vez que a UI esteja pronta, é hora de adicionar funcionalidade de backend:

        1. Configure uma **conta** no [**Supabase**]() e crie um projeto.
        2. Conecte-o ao Lovable pressionando o botão "Connect Supabase".
        3. Para armazenamento de dados, o Lovable gerará tabelas SQL. Por exemplo:

        * Uma tabela `profiles` para armazenar informações do usuário.
        * Uma tabela `meals` vinculada aos usuários para rastrear entradas diárias.

        <Note>
          Use regras de segurança em nível de linha (RLS) no Supabase para garantir a privacidade do usuário. O Lovable pode lidar com isso automaticamente para você.
        </Note>
      </Step>

      <Step title="Integrando OpenAI para Análise de Refeições">
        A magia deste app está em suas capacidades de IA. Para analisar refeições:

        1. Obtenha uma [chave da API OpenAI]() do seu painel de desenvolvedor.
        2. Use [GPT-4]() para analisar descrições ou imagens de refeições.
        3. Certifique-se de que as chaves da API sejam armazenadas com segurança em Edge functions para prevenir acesso não autorizado.

        **Recursos a incluir:**

        * **Analisar descrições de refeições**: Estimar valores nutricionais (calorias, proteína, carboidratos, gordura).
        * **Reconhecimento de imagem**: Faça upload de uma foto da refeição, e o GPT-4 extrairá uma descrição e dados nutricionais.

        <Note>
          *Dicas Pro para Integração OpenAI:*

          * Use **function calling** para respostas estruturadas, garantindo que os dados sejam formatados corretamente para inserção no banco de dados.
          * Teste a funcionalidade pedindo ao app para analisar entradas simples de refeições como "2 ovos."
        </Note>
      </Step>

      <Step title="Implementando Pagamentos com Stripe">
        Para monetizar o app, adicione pagamentos baseados em assinatura:

        1. Crie uma conta no [Stripe]() e configure um produto (ex: "Plano Padrão" por $12/mês).
        2. Integre o Stripe com o Lovable adicionando a chave da API e o ID do preço do produto.
        3. Redirecione usuários não pagantes para a página inicial. Apenas usuários pagantes podem acessar o app principal.

        <Note>
          *Dicas Adicionais:*

          * Habilite o **portal do cliente** do Stripe para permitir que usuários gerenciem assinaturas (ex: cancelar ou atualizar métodos de pagamento).
          * Teste pagamentos no modo de teste do Stripe usando os detalhes de cartão de crédito de teste fornecidos.
        </Note>
      </Step>

      <Step title="Testando e Depurando">
        Erros são uma parte natural do desenvolvimento, e o Lovable simplifica a depuração:

        * Use o botão **"Try to Fix"** sempre que ocorrer um erro de build.
        * Para problemas de backend, verifique os logs do Supabase para relatórios detalhados de erro.
        * Se estiver fazendo deploy no [Netlify](), revise os logs de deployment para quaisquer problemas de build. Compartilhe logs com o Lovable para obter correções personalizadas.

        <Note>
          Se você ficar preso, reverta para uma versão anterior usando o recurso "Revert" do Lovable. Isso economiza créditos e tempo.
        </Note>
      </Step>

      <Step title="Fazendo o Deploy da Sua Aplicação">
        Quando sua aplicação estiver pronta, faça o deploy com Lovable ou Netlify:

        1. Use o recurso de deploy do Lovable para hospedar a aplicação em um domínio padrão.
        2. Para domínios personalizados:

        * Conecte seu [repositório GitHub]() ao Netlify.
        * Compre um domínio e configure as [configurações de DNS]() para vinculá-lo ao Netlify.

        <Note>
          Atualize os metadados da sua aplicação (favicon, meta tags, imagem OG) para melhor branding e SEO.
        </Note>
      </Step>
    </Steps>
  </Accordion>
