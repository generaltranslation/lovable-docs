    No Lovable, a simplicidade é fundamental:

    - [**Aqui**](https://lovable.dev/) **você inicia seu projeto** com um único prompt.
    - **Explore todos os projetos**, incluindo os mais recentes e em destaque.
    - **Comece rapidamente com um template** da nossa seleção curada.
    - **Personalize sua experiência** visualizando e editando seu perfil.
    - [**Gerencie sua conta**](https://lovable.dev/settings) para verificar créditos mensais e ajustar configurações.
    - **Experimente recursos do** [**Labs**](https://lovable.dev/settings/account) como o modo Chat—ative ou desative-os.
    - [**Faça upgrade ou downgrade**](https://lovable.dev/settings/plans) **do seu plano** facilmente.

    No Lovable, cada projeto segue um fluxo de trabalho estruturado:

    - **Edite com facilidade** usando uma interface baseada em chat.
    - **Anexe imagens** para edições precisas e inspiração.
    - **Selecione e edite componentes visualmente** para uma experiência de design fluida.
    - **Alterne facilmente** entre modo de edição e modo de chat.
    - **Acompanhe mudanças** com histórico de versões e restaure qualquer versão anterior.
    - **Navegue pelas páginas** do seu projeto com facilidade.
    - **Habilite remixing** ou renomeie seu projeto conforme necessário.
    - **Integre com Supabase** para capacidades de backend.
    - **Colabore via GitHub** para editar e gerenciar seu código.
    - **Publique, implante e compartilhe** seu projeto com um link de visualização (lembre-se de republicar após mudanças).
    - **Alterne entre visualização web e mobile** para design responsivo.
    - **Atualize o modal de visualização** para ver atualizações instantaneamente.
    - **Abra seu projeto diretamente** usando o link de visualização.
  </Accordion>
  <Accordion title="Configurações do Projeto">

    - **Visualize detalhes importantes do projeto** como total de edições e data de criação.

    - **Conecte a um repositório GitHub** para colaboração fluida.
    - **Ajuste a visibilidade do projeto** de público para privado.
    - **Gerencie a exibição do badge** (disponível apenas para planos pagos).
    - **Renomeie seu projeto** a qualquer momento.
    - **Exclua seu projeto** (⚠️ Zona de Perigo).
  </Accordion>
  <Accordion title="Acesso Rápido do Projeto">

    - **Dashboard** para uma visão geral dos seus projetos.
    - **Configurações da conta** para gerenciar seu perfil e preferências.
    - **Documentação, Portal de Feedback e Suporte** para orientação e assistência.
    - **Sair** com segurança da sua conta Lovable.
  </Accordion>

### Inicie seu Projeto

Existem várias maneiras de começar com o Lovable, dependendo das suas preferências e recursos:

<AccordionGroup>
  <Accordion title="Prompt">
    O sistema baseado em prompts do Lovable torna a criação de aplicativos simples.

    - Apenas descreva o que você quer construir na caixa de prompt.
    - Quanto mais específico você for, melhores serão os resultados.
    - Comece com prompts claros e detalhados.
    - Você pode refinar e ajustar seu projeto conforme avança.

    <Info>
      Exemplo:

      _"Crie um dashboard com login de usuário, vendas mensais em um gráfico de linha e dados demográficos de clientes em um gráfico de pizza."_
    </Info>
  </Accordion>
  <Accordion title="Templates">
    <Steps>
      <Step title="Passo 1">
        O Lovable oferece [templates](https://lovable.dev/templates) para ajudá-lo a começar rapidamente em tipos de projetos populares, como dashboards, sites de e-commerce ou aplicativos sociais, para uma configuração rápida.
      </Step>
      <Step title="Passo 2">
        Assim que o template carregar, use prompts para ajustar recursos, adicionar novos elementos ou ajustar o design para corresponder à sua visão.
      </Step>
    </Steps>
  </Accordion>
  <Accordion title="Remixar um Projeto Existente">
    <iframe width="100%" height="315" src="https://www.youtube.com/embed/lQeLuBMz1oc?si=ZQoC9sZRDqiMkS8P" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen />

    Você pode remixar um projeto público existente ou um dos seus próprios. Remixar permite que você reutilize o estado atual de um projeto como ponto de partida e construa sobre ele. É uma ótima maneira de explorar novas ideias, fazer ajustes ou iterar com diferentes mudanças preservando a versão original.

    <Note>
      Note que não é possível remixar projetos quando o Supabase está conectado.
    </Note>
  </Accordion>
  <Accordion title="Usando Figma">
    Se você tem um design no Figma,

    1. **Usando capturas de tela:** Tire uma captura de tela de qualquer parte dele. Você pode colar a captura de tela diretamente no Lovable ou arrastar e soltar o arquivo de imagem. Assim que você pressionar Enter, o Lovable converterá seu design em código funcional.
    2. **Usando integração Builder.io:** Primeiro, estruture seu design do Figma usando Auto-Layout e nomenclatura clara de camadas. Em seguida, abra o plugin Builder.io no Figma, selecione seu design e clique em "Open in Lovable" para gerar um aplicativo totalmente funcional. [Mais informações aqui.](https://lovable.dev/blog/2025-01-22-figma-to-lovable-builder-io-native-integration)
  </Accordion>
  <Accordion title="Usando um Esboço">
    <Steps>
      <Step title="Passo 1">
        Use [**Excalidraw**](https://excalidraw.com/) ou qualquer ferramenta similar para esboçar sua UI.
      </Step>
      <Step title="Passo 2">
        Tire uma captura de tela do seu desenho, então cole ou arraste e solte no Lovable.
      </Step>
      <Step title="Passo 3">
        A plataforma transformará seu esboço em código funcional.
      </Step>
    </Steps>
    [Mais informações aqui.](https://www.youtube.com/watch?v=c0zhLzcVJRI)
  </Accordion>
  <Accordion title="Clonando um Site ou Aplicativo">
    Se você quer replicar uma página web existente,

    <Steps>
      <Step title="Passo 1">
        Tire uma captura de tela usando atalhos como _Cmd\+Shift\+4_ no Mac ou ferramentas como a [Extensão GoFullPage do Chrome](https://chromewebstore.google.com/detail/gofullpage-full-page-scre/fdpohaocaechififmbbbbbknoalclacl).
      </Step>
      <Step title="Passo 2">
        Cole ou arraste a captura de tela no Lovable
      </Step>
      <Step title="Passo 3">
        O Lovable recriará a estrutura da página web no seu projeto.
      </Step>
    </Steps>
    [Mais informações aqui.](https://www.youtube.com/watch?v=tYDqBMilHkM)
  </Accordion>
</AccordionGroup>

### Edite seu Projeto

<AccordionGroup>
  <Accordion title="Adicionar um Conhecimento Personalizado ao seu Projeto">
    A [Base de Conhecimento](https://docs.lovable.dev/features/precision-edit#knowledge-files) no Lovable atua como o **blueprint** do seu projeto, organizando funcionalidade, design e objetivos em um só lugar.

    ![Screenshot2025 04 23at8 16 42PM Pn](/knowledge-project-lovable.png)

    Siga estes passos para configurá-la e gerenciá-la efetivamente.

    <Steps>
      <Step title="Passo 1">
        Vá para a seção **Base de Conhecimento** no seu painel.
      </Step>

      <Step title="Passo 2">
        Clique em **"Adicionar Entrada"** e categorize-as em:

        * 📌 **Visão Geral do Projeto** – Defina objetivos e escopo.
        * 🚀 **Recursos Principais** – Liste funcionalidades centrais.
        * 🎨 **Diretrizes de Design** – Documente princípios de UI/UX.

        Isso ajuda a manter consistência nos resultados.
      </Step>

      <Step title="Passo 3">
        **Mantenha Atualizado:** Revise regularmente e **atualize entradas** conforme seu projeto evolui. Isso garante que o **desenvolvimento permaneça no caminho certo**.
      </Step>
    </Steps>
  </Accordion>

### Adicione Capacidades Fullstack ao seu Projeto

<AccordionGroup>
  <Accordion title="Conectar um Backend">
    Supabase é uma plataforma backend-as-a-service que se integra perfeitamente com Lovable para adicionar recursos poderosos de backend à sua aplicação.

    <iframe width="100%" height="315" src="https://www.youtube.com/embed/g8CvOq3b-sg" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen />

    <Steps>
      <Step title="Configurar Supabase">
        Crie uma conta no [Supabase](https://supabase.com/) e crie um novo projeto.
      </Step>

      <Step title="Vincular ao Lovable">
        No Lovable, vá para **Configurações -> Conectar Supabase** e siga os passos.
      </Step>

      <Step title="Gerenciar Dados">
        Configure tabelas, gerencie dados de usuário e configure notificações por email.
      </Step>
    </Steps>
  </Accordion>

  <Accordion title="Começando com Supabase">
    Após configurar seu projeto Supabase, você precisará conectá-lo ao seu projeto Lovable. Esta conexão permite que o Lovable aproveite os serviços de backend do Supabase de forma integrada.

    <iframe width="100%" height="315" src="https://www.youtube.com/embed/-sSOyO0FiPE?si=GGrbduHZFrxAGYis" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen />
  </Accordion>

  <Accordion title="Simplifique a Autenticação do Seu App com Supabase">
    Implementar autenticação segura é crucial para qualquer aplicação. Com o construtor de formulários AI do Lovable e a integração com Supabase, você pode criar facilmente formulários robustos de login e cadastro.

    <iframe width="100%" height="315" src="https://www.youtube.com/embed/LHpMUj-Jf_k?si=Rf3zSHuDA_bCBsQb" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" referrerpolicy="strict-origin-when-cross-origin" allowfullscreen />

    Aqui está um guia passo a passo:

    <Steps>
      <Step title="Criar uma Conta Supabase">
        * Visite [Supabase](https://supabase.com/) e cadastre-se.​
        * Acesse o painel para gerenciar seus projetos e bancos de dados.​
      </Step>

      <Step title="Integrar Supabase com Lovable">
        * No Lovable, navegue até as configurações de integração.​
        * Insira a URL do seu projeto Supabase e as chaves da API para estabelecer uma conexão.
      </Step>

      <Step title="Projetar Formulários de Autenticação com Lovable">
        * Use o construtor de formulários AI do Lovable para criar formulários intuitivos de login e cadastro.​
        * Personalize a interface para alinhar com a marca da sua aplicação.
      </Step>

      <Step title="Implementar Fluxos de Autenticação">
        * Configure Supabase Edge Functions para lidar com tarefas como validação de token e sessões de usuário.
        * Garanta o armazenamento seguro das credenciais do usuário e gerencie a persistência da sessão.
      </Step>

      <Step title="Habilitar Verificação por Email">
        * Configure o Supabase para enviar emails de verificação após o registro do usuário.​
        * Isso adiciona uma camada extra de segurança confirmando as identidades dos usuários.
      </Step>

      <Step title="Testar e Implantar">
        * Teste minuciosamente os fluxos de autenticação para garantir experiências de usuário perfeitas.​
        * Uma vez satisfeito, implante sua aplicação com confiança.
      </Step>
    </Steps>

    [Mais informações sobre Supabase aqui.](https://docs.lovable.dev/integrations/supabase)
  </Accordion>
