## Interface do Lovable

<AccordionGroup>
  <Accordion title="O que é o painel do Lovable?">
    O painel é onde você gerencia seus projetos, visualiza seus créditos, controla a visibilidade do projeto e acessa configurações.
  </Accordion>
  <Accordion title="Como devo estruturar meus prompts para obter os melhores resultados?">
    - Seja **claro e específico** (ex.: _"Crie uma página de cadastro com email e senha usando Supabase."_).
    - Evite instruções vagas.
    - Descreva os resultados esperados para orientar a IA.

    Mais informações [aqui](https://docs.lovable.dev/tips-tricks/prompting).

  </Accordion>
  <Accordion title="Como altero a visibilidade do meu projeto?">
    Nas configurações do seu projeto, você pode alternar seu projeto entre modo público e privado.
  </Accordion>
  <Accordion title="O que faz o recurso de chat?">
    O recurso de chat permite que você interaja com a IA do Lovable sem modificar seu código. Você pode fazer perguntas, obter explicações e depurar problemas.
  </Accordion>
  <Accordion title="Posso ver o código que o Lovable gera?">
    Sim, você pode alternar o visualizador de código para inspecionar o código gerado pela IA.
  </Accordion>
  <Accordion title="Posso editar o código gerado?">
    Sim, mas a edição completa de código está disponível apenas em certos planos pagos. No entanto, você pode usar o modo de edição do Lovable para fazer alterações visualmente.
  </Accordion>
  <Accordion title="Como crio uma landing page?">
    Simplesmente digite um prompt como:

    <Info>
      _"Quero construir uma landing page para uma plataforma de IA direcionada a psicólogos."_
    </Info>
    O Lovable gerará uma página baseada na sua entrada.

  </Accordion>
  <Accordion title="Posso importar designs do Figma?">
    Sim, você pode importar arquivos do Figma para o Lovable e usá-los como ponto de partida para seu projeto.
  </Accordion>
  <Accordion title="Como adiciono animações ao meu projeto?">
    Use um prompt como:

    <Info>
      _"Adicione animações legais à seção hero."_
    </Info>
    O Lovable suporta frameworks como P5.js para animações.

  </Accordion>
  <Accordion title="Como conecto meu projeto a um banco de dados?">
    Você pode usar **Supabase**, uma solução de backend-as-a-service que se integra perfeitamente com o Lovable.
  </Accordion>
  <Accordion title="Posso adicionar autenticação ao meu projeto?">
    Sim, você pode integrar autenticação usando Supabase, Clerk ou Magic.link solicitando ao Lovable para criar páginas de login e cadastro.
  </Accordion>
  <Accordion title="Como rastreio mudanças no meu projeto?">
    O Lovable fornece um **recurso de histórico** onde você pode visualizar e restaurar versões anteriores do seu projeto.
  </Accordion>
  <Accordion title="O que é um remix?">
    Remixar um projeto cria uma duplicata que você pode modificar separadamente, permitindo explorar diferentes versões do seu projeto.
  </Accordion>
  <Accordion title="Posso copiar e editar o projeto de outra pessoa?">
    Se um projeto é público e o remix está habilitado, você pode criar sua própria cópia e personalizá-la.
  </Accordion>
  <Accordion title="Posso exportar meu projeto e hospedá-lo em outro lugar?">
    Sim\! Ao vincular seu projeto ao **GitHub**, você pode exportar seu código e hospedá-lo no seu servidor preferido.
  </Accordion>
  <Accordion title="Posso integrar sistemas de pagamento?">
    Sim, o Lovable suporta **Stripe, PayPal e outros provedores de pagamento**. Apenas solicite ao Lovable para configurar o sistema de pagamento que você preferir.

    Siga [este guia](https://docs.lovable.dev/tips-tricks/setting-up-payments) para configurá-lo.

  </Accordion>
  <Accordion title="Posso convidar outros para colaborar no meu projeto?">
    Sim, veja detalhes sobre colaboração [aqui](https://docs.lovable.dev/user-guides/teams).
  </Accordion>
  <Accordion title="Posso exibir meus projetos?">
    Sim\! Você pode compartilhar seu projeto na seção [**Lovable Launch**](https://launched.lovable.app/) e nas redes sociais.
  </Accordion>
  <Accordion title="O Lovable suporta desenvolvimento de aplicativos móveis?">
    Não, o Lovable é focado em **aplicações web**, mas você pode projetar aplicações web responsivas para dispositivos móveis.
  </Accordion>
</AccordionGroup>

## Primeiros Passos

<AccordionGroup>
  <Accordion title="O que é o Lovable?">
    Lovable é uma plataforma alimentada por IA que permite que usuários de qualquer nível de habilidade criem aplicações web full-stack sem necessidade de conhecimento em programação, simplesmente descrevendo o que desejam em português simples. Em vez de contratar desenvolvedores, os usuários podem gerar aplicações web ou sites instantaneamente.
  </Accordion>

  <Accordion title="Como me inscrevo e começo?">
    Simplesmente crie uma conta no Lovable, explore a interface e comece a construir digitando prompts que descrevem o que você quer criar.
  </Accordion>

  <Accordion title="O que posso construir com o Lovable?">
    Você pode construir páginas de destino, aplicações web, ferramentas alimentadas por IA, sistemas de autenticação e muito mais.
  </Accordion>

  <Accordion title="Posso começar a partir de templates?">
    Sim! O Lovable oferece templates pré-construídos para ajudá-lo a começar rapidamente. Navegue por eles [aqui](https://lovable.dev/templates).

  <Accordion title="Como construo um sistema baseado em funções para um app SaaS?">
    Criar um sistema seguro baseado em funções envolve:

    * Usar **autenticação Supabase** para atribuir funções de usuário (Admin, Usuário, Convidado, etc.).
    * Aplicar **Segurança em Nível de Linha (RLS)** para controlar o acesso aos dados para diferentes usuários.
    * Aproveitar **Edge Functions** para segurança da API, garantindo que apenas usuários autorizados possam realizar ações específicas.
  </Accordion>

  <Accordion title="A otimização de prompt conta para o meu limite de uso?">
    Sim, a otimização de prompt pode usar tokens, mas o Lovable é projetado para minimizar interações desnecessárias e maximizar a eficiência.
  </Accordion>

  <Accordion title="Preciso de experiência em programação para construir um app?">
    Não! O Lovable é projetado para todos os níveis de experiência. Seja você um desenvolvedor ou um usuário não técnico, você pode facilmente criar projetos usando assistência de IA.

    O Lovable permite que usuários não técnicos criem apps através de um fluxo de trabalho estruturado: **planejar, solicitar, estruturar, depurar e implantar.** Você pode gerar documentação do projeto, dividir o processo em etapas e deixar a IA guiá-lo.
  </Accordion>

  <Accordion title="Posso aprender programação com o Lovable?">
    Sim! A melhor maneira de aprender é fazendo. O Lovable ajuda você a entender programação:

    * Gerando e explicando código.
    * Encorajando o reconhecimento de padrões nas respostas geradas por IA.
    * Permitindo experimentação e depuração.

    **Recursos de aprendizado recomendados:**

    * [Coding with AI](https://www.loom.com/share/4820c0119b314b26af7faa515666be24?sid=4eac28fc-de30-4500-91d0-535c0b508907) por 50in50Challenge (gratuito)
    * [Build & Launch with Lovable](https://aclasswithharry.com/) por [Harry](https://x.com/Harry_Aldian/status/1892636006056128703) ($20)

    Estes cursos fornecem experiências de aprendizado práticas para ajudá-lo a dominar o Lovable de forma mais eficaz. 🚀
  </Accordion>

  <Accordion title="Quanto tempo leva para construir um app full-stack?">
    Depende da complexidade. Dividindo tarefas em etapas menores, planejando com antecedência e refinando com base no feedback, você pode avançar rapidamente enquanto garante qualidade.
  </Accordion>

  <Accordion title="Como construo meu site com o Lovable?">
    1. **Estruture o site** – Defina seções principais como página inicial, sobre, recursos e depoimentos.
    2. **Design** – Personalize fontes, cores e layouts para uma aparência profissional.
    3. **Adicione conteúdo** – Incorpore imagens, vídeos e texto para torná-lo envolvente.
    4. **Refine e lance** – Otimize a responsividade e garanta interações suaves.
  </Accordion>

  <Accordion title="Preciso de um Chief Technical Officer (CTO) para meu MVP?">
    Não! Se seu projeto é direto, a IA do Lovable pode ajudá-lo a construir e refiná-lo. No entanto, se você planeja escalar rapidamente ou precisa de recursos avançados, ter suporte técnico pode ser benéfico.
  </Accordion>

  <Accordion title="O que devo fazer se encontrar um problema com o Lovable?">
    O Lovable fornece uma ferramenta de depuração orientada por IA que analisa erros em tempo real. Se um erro ocorrer:

    * Clique em "Try to Fix."
    * Use o **Chat Mode** para descrever o problema e peça ao Lovable para depurá-lo.
    * Revise os logs de erro e a saída do console para detalhes adicionais.

    Tente atualizar sua sessão ou [revisar a documentação](https://docs.lovable.dev/tips-tricks/troubleshooting). Se o problema persistir, entre em contato com o **Lovable Support** através da nossa [página de suporte](https://lovable.dev/support).
  </Accordion>

  <Accordion title="O que é o Supabase e como ele ajuda os usuários do Lovable?">
    Supabase é um backend-as-a-service de código aberto que fornece autenticação, bancos de dados (PostgreSQL), armazenamento e recursos em tempo real. Ele ajuda os usuários do Lovable ao lidar com armazenamento de dados, autenticação e outras funcionalidades de backend sem exigir configuração manual.
  </Accordion>

  <Accordion title="Qual é a melhor maneira de estruturar um projeto no Lovable?">
    Comece com o **chat mode** para explorar sua ideia e construir um plano. Só mude para o **edit mode** quando a visão estiver clara. Muitos usuários passam **80% do tempo no chat**, não construindo—**planejando**.
  </Accordion>

  <Accordion title="Posso enviar diagramas ou capturas de tela?">
    Sim! Diagramas (do Miro/FigJam/etc.) e capturas de tela são super úteis—especialmente para fluxos e bugs de UI. Embora vídeos ainda não sejam suportados, capturas de tela muitas vezes podem fazer o trabalho.
  </Accordion>
</AccordionGroup>




## Desenvolvimento e Recursos

<AccordionGroup>
  <Accordion title="Posso baixar o código que o Lovable gera?">
    Sim! Você pode acessar e gerenciar seu código gerado através da nossa [integração com GitHub](/en/integrations/git-integration).
  </Accordion>

  <Accordion title="O Lovable suporta backends personalizados?">
    Sim! O código gerado pelo Lovable pode se conectar a qualquer backend, incluindo [Supabase](https://docs.lovable.dev/integrations/supabase) para gerenciamento de banco de dados e autenticação.
  </Accordion>

  <Accordion title="Quais frameworks o Lovable suporta?">
    Atualmente, o Lovable suporta **Vite e React**. NextJS e React Native ainda não estão disponíveis.
  </Accordion>

  <Accordion title="Como o Lovable lida com código duplicado?">
    A IA agora detecta e remove arquivos duplicados, prevenindo erros e garantindo um gerenciamento limpo do projeto.
  </Accordion>

  <Accordion title="O que é um webhook?">
    Um webhook permite que duas aplicações se comuniquem em tempo real enviando dados quando um evento ocorre (por exemplo, um novo usuário se cadastra, disparando uma notificação por email).
  </Accordion>

  <Accordion title="O que é refatoração e por que é importante?">
    A refatoração melhora a estrutura e eficiência do código sem alterar a funcionalidade. Ela ajuda a:

    * Otimizar a performance removendo redundâncias.
    * Melhorar a manutenibilidade para atualizações futuras.
    * Prevenir conflitos estruturando a lógica de forma mais clara.
  </Accordion>

  <Accordion title="Posso usar o Lovable para desenvolvimento frontend?">
    Sim! O Lovable é perfeito para desenvolvimento frontend, oferecendo:

    * **Desenvolvimento Baseado em Componentes** – Construa com React e Vite.
    * **Geração de Código Assistida por IA** – Gere layouts e componentes de UI facilmente.
    * **Design Mobile-First** – Implemente designs responsivos com Tailwind CSS.
    * **Preview em Tempo Real** – Veja mudanças instantaneamente e faça deploy eficientemente.

    [Confira o artigo completo.](https://lovable.dev/blog/frontend-development-with-lovable)
  </Accordion>

  <Accordion title="Como posso melhorar meu projeto com o Lovable?">
    * **Refine componentes** usando prompts orientados por IA.
    * **Adicione novas funcionalidades** com instruções claras e detalhadas.
    * **Edite elementos de UI diretamente** usando selecionar-para-editar.
    * **Acompanhe e reverta mudanças** através do histórico de versões.
  </Accordion>

  <Accordion title="Qual é a melhor forma de prevenir regressões inesperadas ao validar código?">
    * **Use o modo chat** para verificar mudanças antes de aplicá-las.
    * **Bloqueie arquivos críticos** para prevenir edições não intencionais.
    * **Implemente controle de versão** (GitHub) para rastrear mudanças.
    * **Escreva prompts detalhados** para que a IA entenda as dependências.
  </Accordion>

  <Accordion title="Como posso melhorar o SEO do meu app Lovable?">
    Os apps Lovable são aplicações de página única (SPAs), o que pode impactar o SEO. Para melhorar o SEO:

    * Use **metadados e tags Open Graph**.
    * Otimize para **renderização do lado do servidor (SSR)** usando ferramentas como Vercel.
    * Gere páginas estáticas para melhor indexação.

    Para otimizar seu website para SEO e tráfego, você pode [conferir esta seção](https://docs.lovable.dev/tips-tricks/seo).
  </Accordion>

  <Accordion title="Múltiplos usuários podem colaborar em um projeto Lovable?">
    Esta é uma solicitação de funcionalidade em desenvolvimento.
  </Accordion>

  <Accordion title="Posso usar o Lovable com um domínio personalizado?">
    Sim, você pode configurar [domínios personalizados](https://docs.lovable.dev/tips-tricks/custom-domain) usando **Entri, Vercel, Netlify ou outros serviços de hospedagem**.
  </Accordion>

  <Accordion title="Como faço deploy de um app Lovable?">
    1. Clique no botão **Publish**, e o Lovable fará o deploy do seu projeto para uma URL ao vivo.
    2. O Lovable gerará uma URL compartilhável.
    3. Você também pode conectar para hospedagem com [domínio personalizado](https://docs.lovable.dev/tips-tricks/custom-domain).
  </Accordion>

  <Accordion title="Posso editar o código gerado pelo Lovable?">
    Sim! O Lovable fornece um **Visualizador de Código** que permite aos usuários pagos visualizar e fazer pequenas edições nos arquivos do projeto subjacentes. Você pode habilitar esta funcionalidade em \*\*Configurações da Conta > \*\*
  </Accordion>

  <Accordion title="O que é uma Edge Function?">
    Uma **Edge Function** é uma pequena função serverless no [Supabase](https://docs.lovable.dev/integrations/supabase) que executa lógica no backend, como enviar emails ou processar chamadas de API.
  </Accordion>

  <Accordion title="O que devo incluir no meu Arquivo de Conhecimento?">
    Tudo. Trate-o como um briefing de produto:

    * Visão e objetivos
    * Persona do usuário e jornada
    * Nomenclatura (projeto, empresa, páginas)
    * Detalhamento de funcionalidades
    * Diretrizes como:
      * "Seja incremental ao construir."
      * "Não complique demais."
      * "Siga o sistema de design."

    Adicione uma vez e o Lovable usará em todos os prompts.
  </Accordion>
</AccordionGroup>




## Depuração e Solução de Problemas

<AccordionGroup>
  <Accordion title="O que devo fazer quando encontro um erro que não desaparece?">
    **Ótima pergunta!** Você não está sozinho—todo mundo entra nesses loops às vezes.

    Aqui está o que recomendamos:

    <Steps>
      <Step title="Tente corrigir (gratuito)">
        **Tente corrigir o erro duas vezes** usando o modo de edição ou modo de chat.
      </Step>
      <Step title="Modo Chat">
        Se ainda continuar em loop ou criar mais problemas, **mude completamente para o modo de chat** e depure explicando o que você está vendo.

        Use prompts como:

        - "Explique o erro e como corrigi-lo."
        - "Liste os passos que você está seguindo e por quê."
        - "O que é diferente entre isso e sua solução anterior?"
      </Step>
      <Step title="Restaurar">
        Se isso não funcionar, **restaure uma versão anterior que funcionava**, **remixe o projeto**, ou **reporte** via Discord ou suporte pago.
      </Step>
    </Steps>
    <Info>
      Dica bônus:

      **Adicione um Arquivo de Conhecimento** logo no início com sua visão, regras e estrutura. Esse contexto ajuda a IA a se manter no caminho certo.
    </Info>

  </Accordion>
  <Accordion title="Onde posso obter ajuda se estiver travado?">
    - Use o [**Modo Chat**](https://docs.lovable.dev/features/labs#chat-mode) para assistência da IA.
    - Consulte a [**documentação**](https://docs.lovable.dev/) para orientação.
    - Junte-se à [**comunidade Discord**](https://discord.gg/lovable-dev) para ajuda em tempo real.
  </Accordion>
  <Accordion title="O que devo fazer quando meu app quebra?">
    Aqui está um padrão de recuperação seguro:

    1. **Marque a versão** a cada momento estável.
    2. Se algo quebrar, **não continue construindo**—reverta.
    3. Remixe a partir de uma versão front-end que funciona e reimplemente o backend ou lógica complexa gradualmente.

  </Accordion>
  <Accordion title="Como evito confusão de prompt ou loops?">
    Dê _mais_ contexto, não menos. Prompts longos e estruturados funcionam melhor:

    - Descreva o que o usuário deve ver, clicar e fazer.
    - Esclareça qual parte do app isso afeta.
    - Seja explícito: "Adicione um botão de login que redireciona para o dashboard após o login (Google, Slack, email)."

  </Accordion>
  <Accordion title="Quais opções de suporte eu tenho?">
    2 opções aqui:

    - **Usuários gratuitos**: Ajuda da comunidade via [Discord](https://discord.gg/lovable-dev).
    - [**Usuários pagos**](https://lovable.dev/support): Acesso ao suporte com IA _mais_ a opção "Falar com um humano" a qualquer momento (problemas relacionados à plataforma). Respondemos no mesmo dia para usuários pagos.

  </Accordion>
</AccordionGroup>

## IA e Automação

<AccordionGroup>
  <Accordion title="Posso adicionar APIs de terceiros ao meu projeto?">
    Sim, você pode integrar APIs como OpenAI, Stripe e outras especificando-as no seu prompt.
  </Accordion>
  <Accordion title="Posso armazenar chaves de API sensíveis no Lovable?">
    Não\! Nunca insira suas chaves de API diretamente no Lovable. Se você estiver integrando com uma API, recomendamos que use os secrets do Supabase para armazenar suas chaves de API, em combinação com as [Supabase Edge Functions](https://docs.lovable.dev/integrations/supabase).
  </Accordion>
  <Accordion title="Como a IA do Lovable lembra do contexto?">
    O Lovable processa mensagens recentes para manter o contexto. Para obter os melhores resultados, inclua detalhes relevantes em cada prompt para garantir clareza e precisão.
  </Accordion>
  <Accordion title="O Lovable pode construir aplicações SaaS B2B complexas?">
    Sim\! O Lovable suporta:

    - **Automação de fluxo de trabalho** para processos empresariais.
    - **Controles de acesso baseados em função** para diferentes níveis de usuário.
    - **Geração de documentos** com lógica integrada para aprovações e assinaturas.
    - E muito mais.

  </Accordion>
  <Accordion title="Por que o Lovable migrou do Python para Go?">
    O Lovable migrou [do Python para Go](https://lovable.dev/blog/from-python-to-go) para melhorar performance, escalabilidade e experiência do desenvolvedor. Go permite processamento mais rápido, menor latência e melhor eficiência, especialmente para lidar com tarefas de IA em larga escala.
  </Accordion>
  <Accordion title="Qual é o limite de caracteres para prompts?">
    Devido às limitações da IA, os prompts são limitados a **aproximadamente 180K tokens (≈720K caracteres).**
  </Accordion>
  <Accordion title="Posso executar meu modelo de IA no Lovable sem uma API?">
    Provavelmente não. A maioria dos modelos de IA requer uma API para integração adequada.
  </Accordion>
</AccordionGroup>

## Preços e Configurações da Conta

<AccordionGroup>
  <Accordion title="O que são créditos no Lovable?">
    Créditos são usados para ações alimentadas por IA, como gerar código ou fazer
    edições. Cada mensagem que você envia para a IA custa um crédito.
  </Accordion>
  <Accordion title="Prompts longos e curtos custam o mesmo?">
    Sim, cada mensagem enviada conta como um crédito, independentemente do tamanho.
  </Accordion>
  <Accordion title="Como obtenho mais créditos?">
    Você pode fazer upgrade do seu plano nas Configurações da Conta para acessar mais créditos.
    Mais informações
    [aqui](https://docs.lovable.dev/user-guides/messaging-limits#upgrading-and-downgrading-plans).
  </Accordion>
  <Accordion title="Quando minha contagem de tokens é reiniciada?">
    Mensalmente, na mesma data em que você se inscreveu.
  </Accordion>
  <Accordion title="Posso recarregar meu limite mensal?">
    Não, mas você pode fazer upgrade ou downgrade de planos com base nas suas necessidades.
  </Accordion>
  <Accordion title="Como posso verificar minhas mensagens restantes?">
    Vá para **Configurações da Conta** e verifique a seção **créditos/mensagens restantes**.
  </Accordion>
  <Accordion title="Posso excluir minha conta?">
    Para excluir sua conta, envie um email para **support@lovable.dev**.
  </Accordion>
  <Accordion title="Posso alterar meu email?">
    Atualmente, não é possível alterar seu email vinculado à conta.
  </Accordion>
  <Accordion title="Posso excluir um projeto?">
    Sim\! Navegue para **Configurações do Projeto → Zona de Perigo → Excluir Projeto.**
  </Accordion>
  <Accordion title="Como o Lovable garante a segurança dos dados?">
    O Lovable segue [práticas de segurança padrão da
    indústria](https://lovable.dev/privacy), incluindo criptografia, conexões seguras de API
    e auditorias regulares de segurança para proteger os dados do usuário.
  </Accordion>
</AccordionGroup>

## Sobre o Lovable

<AccordionGroup>
  <Accordion title="Qual é a diferença entre o Lovable e outros construtores de IA?">
    As pessoas dizem que o Lovable tem saídas de maior qualidade, entrega mais rápido, é melhor em full stack e muito mais.
