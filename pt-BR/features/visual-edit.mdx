As Edições Visuais do Lovable permitem que você selecione elementos na página e os edite instantaneamente, como atualizar texto ou cores, ou use prompts para ajustar funcionalidade e layout. Esta ferramenta é útil para fazer atualizações rápidas e direcionadas sem precisar modificar o código manualmente ou usar a IA.

<Note>
  Usar Edições Visuais não deduz créditos.
</Note>

![Visual edits](/assets/features/images/visual-edits.png)

## Quando Usar Edições Visuais

Use Edições Visuais quando você quiser:

- Alterar conteúdo de texto estático em seu site
- Atualizar fontes, tamanhos de fonte ou estilos
- Modificar cores de texto, botões ou outros elementos
- Selecionar um elemento específico e usar prompts para modificar sua aparência visual ou funcionalidade. **Observe** que este prompt deduzirá créditos como um prompt comum.

<Tip>
  **Atalho do teclado:**
  - Option ⌥ \+ S no Mac
  - Alt \+ S no PC
</Tip>

## Como Acessar e Usar Visual Edits
<Steps>
  <Step title="Localizar Visual Edits">
    Você encontrará dentro da caixa de chat no canto inferior esquerdo da interface do seu projeto.
  </Step>
  <Step title="Clique no botão Edit para ativar Visual Edits">
  </Step>
  <Step title="Selecionar o Elemento">
    Passe o mouse sobre o elemento que você deseja alterar; títulos, botões, seções de fundo, etc. Em seguida, clique para selecioná-lo.
  </Step>
  <Step title="Editar via Prompt ou Entrada Direta">
    Após selecionar, você pode:
   - Digitar um prompt como "Deixe este título em negrito e mude a cor para verde escuro."
   - Ou usar as opções de edição inline para alterar diretamente o texto ou selecionar novas fontes e cores.
  </Step>
  <Step title="Aplicar e Revisar">
    Uma vez que sua alteração seja feita, clique em **Save** e o Lovable atualizará instantaneamente a visualização ao vivo e o código.
  </Step>
</Steps>
    
<Warning>
  Apenas elementos estáticos podem ser editados usando a ferramenta Visual Edits. Se um elemento não for selecionável, é muito provável que seja devido a ele ser um elemento dinâmico, que o Visual Edits não consegue selecionar e alterar.
</Warning>
