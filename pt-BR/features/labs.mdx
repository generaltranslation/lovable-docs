## O que é o Labs?

Essas funcionalidades experimentais podem mudar ou ser removidas a qualquer momento.

Você pode acessar o Labs na sua [aba de Configurações da Conta](https://lovable.dev/settings/account) no Editor Lovable.

## **Troca de Branch no GitHub**

Selecione o branch para fazer edições no seu repositório GitHub. Para trocar de branch no GitHub através do editor Lovable:

1. Entre no seu projeto.
2. Vá para Configurações do Projeto
3. Vá para GitHub
4. Clique no dropdown do branch e escolha o branch para o qual você quer trocar.

<Warning>
  ### **Notas Importantes:**

  - Faça commit ou stash de quaisquer mudanças não commitadas antes de trocar de branch
  - Se você encontrar erros de "Branch not found", primeiro puxe as últimas mudanças do repositório remoto
  - Se você não conseguir trocar de branch, verifique se você tem arquivos não rastreados que seriam sobrescritos
  - A troca de branch mudará todos os arquivos no seu workspace para corresponder àquele branch
  - Lovable sincroniza principalmente com o branch padrão do seu repositório (geralmente main)
</Warning>
