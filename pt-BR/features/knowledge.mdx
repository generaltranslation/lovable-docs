Todo projeto tem seus próprios objetivos, restrições e preferências. Use a aba Conhecimento Personalizado para capturar essas informações. Tudo que você adicionar aqui é lembrado e aplicado em todo o seu projeto, tornando as edições mais inteligentes e alinhadas.\
\
Você não precisa ser abrangente. Algumas linhas de direcionamento claro podem fazer uma grande diferença.

## **O que incluir no seu Custom Knowledge**

Aqui estão alguns exemplos de conhecimento útil para adicionar:

- **Diretrizes do projeto**: O que priorizar, o que evitar ou como as decisões devem ser tomadas.
- **Personas de usuário:** Descrições detalhadas dos seus usuários-alvo e suas necessidades.
- **Assets de design:** Paletas de cores, tipografia, regras de layout e outros elementos visuais.
- **Convenções de código**: Convenções de nomenclatura, regras de formatação e estrutura de arquivos.
- **Referências externas**: Links para documentação de APIs, ferramentas internas, design systems ou guias de estilo.
- **Práticas de segurança:** Diretrizes para codificação segura, proteção de dados e manuseio de informações sensíveis.
- **Requisitos de conformidade:** Quaisquer requisitos legais ou regulamentares que seu projeto deve seguir.

## **Dicas para usar Custom Knowledge**

- **Comece pequeno.** Mesmo algumas linhas podem fazer uma diferença significativa.
- **Pense nisso como memória compartilhada.** Tudo que você escrever aqui é lembrado e usado em edições futuras.
- **Mantenha atualizado.** Atualize conforme seu projeto evolui para permanecer alinhado e relevante.
